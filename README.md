# alejandroperretg.github.io

Personal site of Alejandro Perret-Gentil, served at https://alejandroperretg.github.io in
English and Spanish (`/es/`).

A small Python build script renders every page from shared templates; GitHub Actions builds
and deploys it on every push to `main`.

```
build.py                 renders pages/<lang>/*.html into _site/ (EN at /, ES at /es/)
templates/base.html      head, header, language and theme toggles, footer
templates/project.html   shared layout for project pages
pages/en/, pages/es/     page bodies, one file per page and language
strings/en.json, es.json shared labels (navigation, contact, buttons)
static/                  site.css, site.js, favicon, img/, fonts/ (self-hosted, SIL OFL)
cv/                      CV PDF (replace the file, keep the name)
scripts/check_site.py    link, hreflang, third-party-resource, contact-detail and contrast checks
scripts/fetch_fonts.py   one-off download of the web fonts
```

## Work on it

```
uv sync
uv run python build.py --serve        # build and preview at http://localhost:8000
uv run python scripts/check_site.py   # run the checks on the built site
```

To add a page, add `pages/en/<slug>.html` and `pages/es/<slug>.html` and register the slug in
`PAGES` in `build.py`.

## Charts

Charts are inline SVGs styled only by CSS classes, so they follow the light and dark themes.
They sit between `<!-- chart:NAME -->` markers and are regenerated by scripts. The
investor-toolkit charts come from that project's `scripts/site_charts.py`; the thesis charts
are generated by a script that is not published yet.

## Privacy

Every font, script and image is served from this site; `check_site.py` fails the build if a
page loads anything from another server. The privacy notice is at `/privacy/`.
